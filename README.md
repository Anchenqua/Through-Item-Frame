# 无视物品展示框

一个简单的 mod，用于在物品展示框上有物品时无视物品展示框，打开展示框后面的容器。

· 纯客户端 mod，无需服务器支持

![Logo](https://github.com/Anchenqua/Through-Item-Frame/blob/26.1-fabric/src/main/resources/assets/through-item-frame/icon.png?raw=true)

## 构建

同步对应游戏版本的分支，执行

```bash
  ./gradlew build
```

## 兼容

- 与 [Fast Item Frames](https://modrinth.com/mod/fast-item-frames) 兼容：
  - 不潜行右键：打开展示框后面的容器
  - 潜行右键：旋转物品
  - 潜行左键：隐藏/显示展示框
